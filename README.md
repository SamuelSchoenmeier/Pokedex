# Pokedex

A Pokedex website built with HTML, CSS and JavaScript using the PokeAPI. It features Pokémon search, detailed information, stats, abilities, evolution chains and a responsive design.

## Technologies

- HTML
- CSS
- JavaScript
- PokeAPI
- Bootstrap


## API

This project uses the [PokeAPI](https://pokeapi.co/) to retrieve Pokémon data.


## Installation

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Start the project with Live Server.
